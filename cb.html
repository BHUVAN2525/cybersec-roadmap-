Build the technical base every cybersecurity professional needs

Before cybersecurity — master the fundamentals. Security is applied computer science. Without solid networking, OS, and programming knowledge, advanced security topics become guesswork. These phases form the irreplaceable bedrock.

  • IP addressing, subnetting, CIDR notation
  • Core protocols: DNS, DHCP, HTTP/S, FTP, SSH, SMTP, SNMP
  • Routing & switching — VLANs, ARP, NAT, firewalls
  • Wireshark — capture and analyze real traffic
  • Packet Tracer / GNS3 for lab practice

Career Paths: SOC vs Pentesting

Deep dive into the two main professional tracks

🔵

SOC Analyst

Defend organizations by monitoring, detecting, and responding to threats in real-time. You are the immune system of IT infrastructure.

T1

Tier 1 — Alert Triage

Monitor SIEM dashboards, categorize alerts, first-level filtering of false positives. Tools: Splunk, QRadar, Microsoft Sentinel.

T2

Tier 2 — Incident Investigation

Deep-dive analysis on escalated alerts. Correlate events, analyze malware behavior, perform host forensics. Write investigation reports.

T3

Tier 3 — Threat Hunting

Proactively search for undetected threats. Use threat intelligence feeds, build detection rules, mentor junior analysts.

IR

Incident Response Lead

Coordinate response to major incidents. Lead forensic investigations, containment, eradication, and recovery operations.

★

Key Resources

Blue Team Labs Online · Splunk Training · SANS FOR508 · TryHackMe SOC Level 1 & 2 · BTL1 certification

🔴

Penetration Tester

Simulate real attackers to find vulnerabilities before malicious hackers do. You think like an adversary to protect the organization.

P1

Junior Pentester

Run vulnerability scans, test known CVEs, work on CTFs and HackTheBox. Assist senior testers. Learn methodologies: PTES, OWASP, OSSTMM.

P2

Mid-Level — Web & Network

Independently test web apps (OWASP Top 10), network infrastructure. Write professional pentest reports with CVSS-scored findings.

P3

Senior — Advanced Exploitation

Active Directory attacks, custom exploit development, bypass EDR/AV, complex environments. Lead assessments and mentor juniors.

RT

Red Team Operator

Full adversary simulation campaigns. C2 infrastructure, physical intrusion, social engineering. APT-style multi-phase operations.

★

Key Resources

HackTheBox · PortSwigger Web Academy · TCM Security · TryHackMe · OSCP (OffSec PG Practice) · Bug Bounty platforms

OWASP Top 10 — Web Vulnerabilities

The 10 most critical web application security risks — every pentester and SOC analyst must know these

A01 · Critical
Broken Access Control
  • Users can act outside intended permissions
  • IDOR — access other users' data via ID manipulation
  • Privilege escalation by modifying JWT or cookies
  • Force browsing to authenticated pages
  • Test: Burp Suite, manual parameter tampering
IDORAuth Bypass
A02 · Critical
Cryptographic Failures
  • Sensitive data transmitted in cleartext (HTTP, FTP)
  • Weak or deprecated algorithms (MD5, SHA1, DES)
  • Hardcoded secrets and keys in source code
  • Improperly implemented TLS/SSL
  • Test: Wireshark, SSL Labs, git-secrets
TLSSecrets
A03 · Critical
Injection
  • SQL injection — manipulate database queries
  • Command injection — execute OS commands
  • LDAP, XPath, NoSQL injection variants
  • User-controlled data sent to interpreter without validation
  • Test: SQLmap, manual payload crafting
SQLiRCE
A04 · High
Insecure Design
  • Missing or ineffective security controls by design
  • No rate limiting on sensitive endpoints
  • Business logic flaws (skip payment, bypass steps)
  • Missing threat modeling in SDLC
  • Test: Logic flow analysis, abuse cases
Logic FlawsSDLC
A05 · High
Security Misconfiguration
  • Default credentials left unchanged
  • Verbose error messages leaking internals
  • Unnecessary features enabled (debug mode)
  • Cloud storage buckets publicly accessible
  • Test: Nikto, Nmap scripts, cloud config audit
DefaultsCloud
A06 · High
Vulnerable Components
  • Outdated libraries with known CVEs
  • Unpatched OS / web server versions
  • Unmaintained third-party dependencies
  • Log4Shell, Spring4Shell as real-world examples
  • Test: OWASP Dependency-Check, Snyk, retire.js
CVEsSCA
A07 · High
Identification & Auth Failures
  • Weak or default passwords allowed
  • Credential stuffing not prevented
  • Missing MFA on sensitive accounts
  • Exposed session tokens in URLs
  • Test: Hydra, credential stuffing tools
Brute ForceSessions
A08 · High
Software & Data Integrity Failures
  • Insecure deserialization — arbitrary code execution
  • CI/CD pipeline not secured (supply chain attacks)
  • Auto-update without integrity verification
  • SolarWinds / XZ Utils as real-world examples
  • Test: Deserialization gadgets, supply chain audit
DeserializationSupply Chain
A09 · Medium
Security Logging & Monitoring Failures
  • Logins and failures not logged
  • Logs not monitored — breaches go undetected for months
  • Alerts not triggered on suspicious activity
  • Average breach detection time: 200+ days
  • Defend: SIEM, alerting rules, log retention
SIEMDetection
A10 · Medium
Server-Side Request Forgery (SSRF)
  • Server fetches attacker-controlled URLs
  • Access internal metadata services (AWS 169.254.x)
  • Pivot to internal network from web app
  • Bypass firewall rules via trusted server
  • Test: Burp Collaborator, internal IP payloads
SSRFCloud

Active Directory Attack Paths

The most targeted enterprise environment — essential for both red and blue teams

Why AD matters: Over 90% of Fortune 500 companies use Active Directory. Compromising AD = owning the entire organization. Most ransomware attacks pivot through AD to deploy across all machines.
🎯 Kerberoasting
SPN Ticket Cracking
  • Request TGS tickets for Service Principal Names
  • Tickets encrypted with service account NTLM hash
  • Crack offline with Hashcat (mode 13100)
  • Tool: Rubeus.exe kerberoast
  • Defense: Use Group Managed Service Accounts (gMSA)
🎯 DCSync Attack
Domain Controller Replication
  • Mimic DC replication to pull all NTLM hashes
  • Requires: Replicating Directory Changes permissions
  • Dump krbtgt hash → Golden Ticket attack
  • Tool: mimikatz lsadump::dcsync
  • Defense: Monitor DS-Replication event IDs
🎯 Golden Ticket
Forged Kerberos Tickets
  • Forge TGTs using stolen krbtgt hash
  • Valid for any user, any group, any time
  • Persists even after password resets
  • Tool: mimikatz kerberos::golden
  • Defense: Reset krbtgt password TWICE
🎯 Pass-the-Hash
NTLM Hash Reuse
  • Use NTLM hash without cracking the password
  • Authenticate to remote systems laterally
  • Works against SMB, WMI, RDP (with creds)
  • Tool: CrackMapExec smb -H [hash]
  • Defense: Enable Protected Users group, LAPS

Malware Analysis

Understanding how malware works — essential for SOC and threat intel roles

🔬 Static Analysis
Analyze Without Running
  • Hash identification — MD5/SHA256, check VirusTotal
  • String extraction — strings malware.exe for IoCs
  • PE header analysis — imports, sections, entropy
  • Disassembly — IDA Pro, Ghidra (free), Binary Ninja
  • YARA rule writing to detect malware families
  • Identify packers with PEiD / Detect-It-Easy
  • Check imports for suspicious API calls (VirtualAlloc, WriteProcessMemory)
GhidraYARAVirusTotal
🧪 Dynamic Analysis
Observe Live Behavior
  • Snapshot VM before execution — restore after
  • Process Monitor — file/registry/network activity
  • Wireshark — capture C2 traffic and DNS queries
  • API Monitor — trace Windows API calls in real time
  • x64dbg / OllyDbg for dynamic debugging
  • FakeNet-NG — simulate internet to capture beacons
  • Cuckoo Sandbox / Any.run for automated detonation
Cuckoox64dbgAny.run

RAT (Remote Access Trojan)
Malware Type
Gives attacker full remote control. Keylogging, screenshot capture, file exfil, webcam access. Examples: njRAT, AsyncRAT, Quasar.
💰
Ransomware
Malware Type
Encrypts files, demands payment. Modern strains exfiltrate data first (double extortion). Examples: LockBit, REvil, BlackCat.
👻
Rootkit
Malware Type
Hides malware presence at kernel or hypervisor level. Extremely persistent. Requires offline forensics or UEFI scanning to detect.
🤖
Botnet
Malware Type
Network of infected machines (bots) controlled via C2. Used for DDoS, spam campaigns, credential stuffing. Examples: Mirai, Emotet.
🕵
Spyware / Infostealer
Malware Type
Silently harvests credentials, browser cookies, clipboard data. Examples: Redline, Vidar, Raccoon Stealer. Common in phishing.
📎
Fileless Malware
Malware Type
Runs entirely in memory — no file written to disk. Uses PowerShell, WMI, or LOLBins. Very hard to detect with file-based AV.

Incident Response Process

NIST SP 800-61 framework — the structured approach to handling security incidents

📋 Incident Severity Levels
  • P1 Critical — Active ransomware, data breach in progress, DA compromised
  • P2 High — Confirmed malware, unauthorized privileged access
  • P3 Medium — Phishing email clicked, suspicious lateral movement
  • P4 Low — Policy violation, port scan from external
🔍 Digital Forensics — Key Artifacts
  • Windows: Event logs, prefetch, registry, $MFT, Amcache, LNK files
  • Linux: /var/log/auth.log, bash_history, /proc/, crontab, syslog
  • Network: PCAP files, NetFlow/IPFIX, firewall logs, DNS logs
  • Memory: Volatility for RAM forensics, process trees, network conns
📁 Key IR Tools
  • Volatility3 — Memory forensics framework
  • Autopsy / FTK — Disk forensics GUI
  • KAPE — Rapid triage artifact collection
  • Velociraptor — Live endpoint forensics at scale
  • TheHive — Open source IR case management

GRC — Governance, Risk & Compliance

The business side of security — frameworks, regulations, and risk management

📐 NIST CSF 2.0
Cybersecurity Framework
  • GOVERN — Policies, roles, risk strategy (new in 2.0)
  • IDENTIFY — Asset inventory, risk assessment
  • PROTECT — Access controls, training, data security
  • DETECT — Anomalies, continuous monitoring
  • RESPOND — Incident response plans
  • RECOVER — Restore services, communications
🏛 ISO 27001
Information Security Management
  • International standard for ISMS
  • 114 controls across 14 domains
  • Risk assessment and treatment methodology
  • Certification audited by accredited body
  • Required by many enterprise contracts
  • Pairs with ISO 27002 (implementation guidance)
💳 PCI DSS v4.0
Payment Card Industry
  • Mandatory for any org processing card payments
  • 12 requirements covering network, access, encryption
  • Quarterly external vulnerability scans
  • Annual penetration test required
  • SAQ (Self-Assessment) or QSA audit
  • Non-compliance = fines + loss of card processing
🏥 HIPAA
Health Data Security (US)
  • Protects PHI — Protected Health Information
  • Administrative, physical, technical safeguards
  • Breach notification within 60 days
  • Business Associate Agreements required
  • OCR investigates violations — fines up to $1.9M
  • Encryption of PHI at rest and in transit
🇪🇺 GDPR
EU Data Protection Regulation
  • Applies to any org handling EU citizens' data
  • 72-hour breach notification to supervisory authority
  • Right to erasure, data portability, access
  • Privacy by design and by default
  • Fines up to 4% of global annual turnover
  • Data Protection Officer (DPO) role required
📊 Risk Management
Core Concepts
  • Risk = Threat × Vulnerability × Impact
  • Risk appetite — how much risk is acceptable
  • Qualitative vs quantitative risk assessment
  • Treat / Tolerate / Transfer / Terminate (4T)
  • CVSS scoring — base, temporal, environmental
  • Risk register — document, track, and review
