## 🚀 Quick Start

**Absolute beginner? Start here:**

```
Week 1–2  → Set up Kali Linux VM + complete Linux basics on TryHackMe
Week 3–4  → Networking fundamentals (TCP/IP, OSI, Wireshark)
Month 2   → Start Security+ study (Professor Messer free videos)
Month 3   → Complete TryHackMe Pre-Security path (free)
Month 4   → Start Hack The Box Starting Point machines
Month 5   → Choose your track: SOC Analyst OR Penetration Tester
Month 6   → Book your first certification exam
Month 7+  → Enter your first CTF, build GitHub projects
```

## 🎯 Career Tracks Covered

### 🛡️ SOC Analyst Track
```
Security+ → CySA+ → Splunk Core → BTL1 → GCIH → GCFA
```
- SIEM mastery (Splunk, ELK, Microsoft Sentinel)
- Log analysis & threat hunting
- Incident response lifecycle
- Digital forensics fundamentals
- SOAR automation & playbooks

### ⚔️ Penetration Testing Track
```
eJPT → PNPT → CEH → OSCP → OSCE3
```
- Full PTES methodology
- Web application hacking (OWASP Top 10)
- Active Directory attacks
- Red team operations & C2 frameworks
- Professional report writing
